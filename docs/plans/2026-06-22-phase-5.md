# Phase 5: Search & Polish Implementation Plan

> **For Antigravity:** REQUIRED WORKFLOW: Use `.agent/workflows/execute-plan.md` to execute this plan in single-flow mode.

**Goal:** Implement global full-text search with Meilisearch and add global keyboard shortcuts (Cmd+K).

**Architecture:** Add a global `SearchModal` (command palette style) opened via `Cmd+K` or a button in the sidebar. The search modal will hit the existing `/api/emails/search` endpoint powered by Meilisearch. Selected emails will route the user to `/accounts/[accountId]/inbox?emailId=[id]`. We will also add a `ShortcutProvider` for global hotkeys (Cmd+C for compose).

**Tech Stack:** Next.js App Router, Tailwind CSS, Lucide React, Meilisearch API.

---

### Task 1: Search Modal UI & Hook

**Files:**
- Create: `src/components/search/SearchModal.tsx`
- Create: `src/hooks/useSearch.ts`

**Step 1: Write the search hook**
Implement `useSearch` using React Query to call `/api/emails/search` with debouncing.

**Step 2: Build the Search Modal**
Implement an absolutely positioned or fixed modal (like a command palette) with an input field and a list of results. Clicking a result should `router.push('/accounts/[accountId]/inbox?emailId=[id]')`.

**Step 3: Integrate into layout**
Modify `src/app/(dashboard)/layout.tsx` to include `<SearchModal />`.

### Task 2: Keyboard Shortcuts & Sidebar Trigger

**Files:**
- Create: `src/components/providers/ShortcutProvider.tsx`
- Modify: `src/components/sidebar/Sidebar.tsx`
- Modify: `src/app/(dashboard)/layout.tsx`

**Step 1: Shortcut Provider**
Create a component that listens for `keydown` events:
- `Cmd+K` / `Ctrl+K`: Opens Search Modal (can dispatch an event or use Zustand store).
- `Cmd+C` / `Ctrl+C`: Opens Compose Modal.

Wait, we need a Zustand store or React Context to control modal visibility.
- Create: `src/stores/uiStore.ts` with `isSearchOpen` and `setSearchOpen`.

**Step 2: Sidebar Search Button**
Add a "Search... (Cmd+K)" button at the top of `Sidebar.tsx` right under the user profile, replacing or above the "All Inboxes" section.

**Step 3: Integrate**
Wrap `layout.tsx` with `ShortcutProvider` and connect the search button to `uiStore.setSearchOpen(true)`.
